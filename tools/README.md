# Question-bank tools

The app's questions are generated, not hand-written in the app files.

## Rebuild after changing questions
    python3 tools/bank/export_app.py
This rewrites `data/questions.js`, `renderer/practice.js`, `renderer/quiz.css`, and `tools/bank/quiz.html` (the standalone web quiz).

## Where the questions live
- `tools/bank/b1.py` to `b4.py`: 196 questions from the practice PDFs. Each file has `S` (source label) and `B = [(question, [options], answerIndex, rationale), ...]`.
- `tools/bank/bank5.json`: 54 questions from the class PowerPoints. `a` is an index, or a list of indexes for select-all-that-apply. `t` is a topic code from `tmap.py`.
- `tools/bank/tmap.py`: topic for each of the first 196 questions (`M`) and the topic names (`TOP`).
- `tools/bank/tpl.html`: the quiz UI template (progress tracking, resume, select-all, follow-up chat).
- `tools/bank/build.py`: merges everything into one question list.

## Slide question extraction (for new PowerPoints)
`tools/slides/dump.js` parses decks to JSON, `auto.py` pairs question slides with answer slides ("Yes/No" explanations), and `mk5.py` builds `bank5.json` (it also holds hand-written entries for slides with no answer slide). These scripts were run from a scratch folder, so adjust paths as needed.

## Not covered
The Windows installer is built by GitHub Actions on each push to `main`, not locally.

## Medications tab
`data/meds.js` is generated. `python3 tools/meds/build_meds.py` scans the bundled decks (including the ATI guide, not the syllabus) and the question bank for every name in `tools/meds/lexicon.py`, and records where each medication appears. The lexicon only decides what to look for and which category/class a drug is filed under; everything shown about a drug comes from the student's own materials. Add `--report` to list drug-like words that are in the materials but missing from the lexicon. Re-run it after adding decks or questions.

## Weekly quizzes
`tools/quiz/` holds the end-of-week quiz questions exactly as supplied (`quiz_unique.json`, 252 unique multiple-choice questions from 13 quiz versions) and, for each one, whether its answer was checked against the class PowerPoints and where (`checks.json`). `python3 tools/quiz/build_bank7.py` writes `tools/bank/bank7.json`, which `build.py` appends after the other banks (so existing question ids never change). The checks use the PowerPoints only, not the ATI guide or syllabus. Matching, fill-in and image-only items from the source file are not included. After changing the bank, run `export_app.py` and then `tools/meds/build_meds.py`.

## Medical terms glossary
`data/glossary.js` is generated by `python3 tools/glossary/build_glossary.py`. `general.py` holds the general reference terms (standard definitions, including word parts and abbreviations); `build_glossary.py` lists the terms the class PowerPoints and ATI guide define themselves and copies those definitions word for word with the slide or page cited (checked by the tests). A term in both uses the class definition. Add `--show` to print the class-material entries.


## Course content is private (course pack)
Everything copied from Galen / ATI materials (slide decks in `data/seed`, the question banks, the cited slide lines, quoted glossary entries) is NOT committed and NOT in the installer. The generators still write the full data into `data/`; then run
`python3 tools/pack/build_pack.py --strip` to write `content/NurseDesk-CoursePack.zip` (the file classmates import in Settings > Course pack) and remove the course content from `data/` before committing.
The private sources (`tools/bank/b1-b4.py`, `bank5-7.json`, `tools/quiz/*.json`, `tools/slides/*.py`, `data/seed`, `data/questions.js`) are git-ignored; keep your own backup.
